## 🚀 Quick Setup

```bash
# 1. Install Ollama (Free AI)
curl -fsSL https://ollama.ai/install.sh | sh
ollama pull llama3.1  # Free 8B model

# 2. Install Stable Diffusion (Free Images)
pip install diffusers torch transformers

# 3. Already have FFmpeg and MongoDB setup

# 4. Start your FREE AI brain
npm start
```
