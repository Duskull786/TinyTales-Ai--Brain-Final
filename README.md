## 🔧 Configuration

All configuration is in `.env` - **No API keys needed for FREE version!**

```bash
# Database (defaults to local MongoDB)
MONGODB_URI=mongodb://localhost:27017/tinytales

# Content Settings
CONTENT_SCHEDULE_CRON=0 9 * * *  # Daily at 9 AM
TIMEZONE=America/New_York

# FREE Tools (auto-configured)
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.1
EDGE_TTS_VOICE=en-US-AriaNeural
```
